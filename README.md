# HD2-General-Brasch
基于 SHODAN-Stat-Editor 修改的 绝地潜兵2外置修改器
> 修改部分源码未开源，但提供 发行版 供各位下载

## 与上游的区别
1.护甲「词条」自由组合：护甲页 →「+ 添加词条」直接列出所有被动的所有词条（按名排序、标注来源被动），点一下加入；加词条＝替换原整条被动，想叠加原被动再加「+ 添加被动」。

2.词条数值就地编辑：点数值输入、-/+ 步进（Shift 大步）、R 恢复来源被动的值；覆盖值写进 config.txt 并随预设保存。

3.上限放宽：单独词条不限、整被动叠加 14 → 40、军械库文字说明 3 → 4 条。

4.载具挂载点换武器：车辆/机甲页的每个挂载点显示当前武器 + 16 位实体哈希，可直接输入任意哈希（0＝空）或用 +/- 在武器列表里切换（机甲双臂、FRV 炮位、坦克 5 个挂载点等 10 台载具）。

5.设置与更新：更新新增「不提醒」（完全不检查）、「立刻检查」（马上查一次）。 

6.编辑器新增「游戏内文本」开关，默认关，关掉后隐藏页面底部的名称/描述输入框。

7.输入与列表：输入框支持 Shift+←/→ 选字（选中处盖白色）、Ctrl+A 全选、Ctrl+C 复制（UTF-16，中文正常），选中后打字/退格直接替换或删除。 

8.点 * 的「只显示已改内容」列表：Ctrl+单击 多选、Shift+单击 连选、Del 恢复默认、Esc 取消。
